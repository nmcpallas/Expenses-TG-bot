# Bot Flow v2: Setup

Документ-навигация по настройкам запуска.

Пользовательские сценарии описаны отдельно: [README.md](README.md).

## Документы

- [LOCAL_SETUP.md](LOCAL_SETUP.md) - локальная разработка: Java из IntelliJ IDEA, Postgres через Docker Compose, mock ML.
- [PROD_SETUP.md](PROD_SETUP.md) - production/runtime настройки: env, database, Telegram token, real ML/gRPC.

## Быстрый выбор

Для проверки user-flow в тестовом Telegram-боте используй:

```text
LOCAL_SETUP.md
```

Для деплоя или настройки окружения с реальным ML-сервисом используй:

```text
PROD_SETUP.md
```
